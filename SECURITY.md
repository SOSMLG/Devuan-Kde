# Security policy

## Supported versions

Only the current `main` branch is supported. Security fixes land there first.

## Reporting

Use the repository's Security tab and choose "Report a vulnerability". Do not open a public issue for exploit details or secrets.

## Scope

These setup scripts install packages and write user configuration. Run the read-only verifier before trusting a change.

## Secrets

Keep keys, passwords and tokens in the environment or GitHub Secrets. Never commit them.
